# Cyber Safety Buddy

Статичен сайт с три serverless API функции, публикувани заедно във Vercel.

## API адреси

- `POST /api/checkEmailLeak` — проверява имейл чрез LeakCheck. Имейлът се изпраща към LeakCheck за справка и не се пази от приложението.
- `POST /api/checkLink` — търси подозрителни белези в линк и допълва резултата от VirusTotal, ако има зададен ключ.
- `POST /api/trackEvent` — записва анонимни събития в логовете на функцията.

Проверката на пароли се изпълнява в браузъра и не изпраща паролата към API.

## Публикуване

Проектът е свързан с GitHub. Промяна в `main` задейства автоматичен deploy във Vercel. Vercel обслужва статичните файлове от корена (`index.html`, `script.js`, `style.css`) и API функциите от `api/`.

## Незадължителна настройка

Добави `VIRUSTOTAL_API_KEY` в Project Settings → Environment Variables във Vercel, ако искаш живи VirusTotal справки. Без него проверката на линкове пак работи с локалните проверки.

Този проект използва безплатния Vercel Hobby план за лично/учебно използване. Безплатният план има ограничения за използването на функциите; виж [официалните лимити](https://vercel.com/docs/plans/hobby).
